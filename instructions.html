General Instructions for Everyone

Project Structure

src/
├── components/
│   ├── common/   (Navbar, Footer, Loader)
│   ├── auth/     (LoginForm, SignupForm)
│   └── feature/  (Feature-specific)
├── pages/        (Route pages)
├── contexts/     (Context providers)
├── hooks/        (Custom hooks)
├── utils/        (Helpers, API calls)
├── assets/
├── App.jsx
└── index.css     (Tailwind imports)

Quick Setup

cd react-projects/studentX-xxx
npx create-react-app .
npm install react-router-dom tailwindcss
  postcss autoprefixer
npm install react-icons react-toastify uuid
npx tailwindcss init -p
npm start
Recommended Build Order
  1. Setup - Create React app, install deps, configure Tailwind
  2. Routing - Set up React Router with placeholder pages
  3. Auth - Build AuthContext, Login, Signup, ProtectedRoute
  4. Layout - Build Navbar, Footer, common components
  5. Core Feature - Build the main feature (resources, products, etc.)
  6. CRUD - Implement Create, Read, Update, Delete
  7. Search/Filter - Add search and filter functionality
  8. API Integration - Connect to external APIs
  9. File Upload - Implement file upload features
  10. Polish - Loading states, errors, toasts, responsive
Important Notes
  • Each student works in their own folder (no conflicts!)
  • Use Tailwind CSS for all styling (no Bootstrap in React apps)
  • Use Context API for state management (no Redux needed)
  • Use localStorage for data persistence (no backend needed)
  • Never commit .env files or node_modules/
  • Test thoroughly before committing

Contexts:
AuthContext ResourceContext NotificationContext
🔐
Authentication & Profile

  • Role selection: Student or Tutor
  • localStorage persistence
  • Protected routes
  • User profile with stats dashboard
  • Edit profile (name, bio, avatar)
📚
Resource Management
  • Upload materials with file preview
  • Fields: title, description, subject, grade
  • Browse all resources
  • Search by title or description
  • Filter by subject and grade level

⭐
Ratings & Bookmarks
  • 5-star rating system
  • Text reviews on resources
  • Bookmark/favorite resources
  • View bookmarked resources list
💬
Messaging

  • View sent/received messages
  • Message notifications
