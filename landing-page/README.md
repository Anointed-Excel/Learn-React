# React Projects - Landing Page

This is the showcase hub for all 5 React portfolio projects.

## How to View

Simply open `index.html` in your browser:

```bash
open index.html
# or double-click the file
```

## What It Shows

- All 5 student projects with descriptions
- Key features for each project
- Routes and Contexts required
- Technology stack per project
- Complexity indicators
- Link to full student instructions

## Customization

To update the landing page:
1. Edit `index.html`
2. Modify student cards, descriptions, or styling
3. Update links if needed

## Design

- Built with Bootstrap 5 and custom CSS
- Purple/Violet gradient theme (matching React/Tailwind aesthetic)
- Responsive design for all screen sizes
- Color-coded student cards (Indigo, Emerald, Orange, Rose, Violet)
